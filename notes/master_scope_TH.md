# Master Scope Document
## Southern Thailand Regional Economic Dashboard

> เอกสารนี้ใช้เป็น "กระดูกสันหลัง" อ้างอิงสำหรับทั้ง 4 Project ย่อย เพื่อให้ scope, ช่วงเวลา, และหน่วยวัดตรงกัน สามารถนำมารวมเป็น Dashboard เดียวได้ตอนจบ

---

## 1. หัวข้อวิจัยหลัก (Research Questions)

| # | Project | คำถามหลัก |
|---|---------|-----------|
| 1 | **Opportunity Mapping** | สามจังหวัดชายแดนใต้เหมาะกับธุรกิจ/เซคเตอร์แบบไหน และเซคเตอร์ไหนโตเร็วที่สุดในช่วง 5 ปีที่ผ่านมา |
| 2 | **Development Priority** | ปัจจัยอะไรที่เป็นคอขวด (bottleneck) ฉุดรั้งศักยภาพเศรษฐกิจพื้นที่มากที่สุด และควรพัฒนาอะไรก่อน |
| 3 | **Risk Factor Analysis** | ปัจจัยเสี่ยงหลักที่กระทบเศรษฐกิจพื้นที่ (เชิงโครงสร้าง / เชิงความปลอดภัย / เชิงตลาดโลก) |
| 4 | **Vulnerable Sectors** | จากปัจจัยเสี่ยงในข้อ 3 ธุรกิจ/เซคเตอร์ไหนเสี่ยงขาดทุนหรือหดตัวมากที่สุด |

**Logic Flow:** โอกาส → ควรพัฒนาอะไร → ความเสี่ยงคืออะไร → ใครที่ต้องระวัง
**Deliverable สุดท้าย:** รวม 4 Project เป็น Dashboard เดียว (1 ชิ้นใหญ่)

---

## 2. พื้นที่ศึกษา (Geographic Scope)

**ครอบคลุม:**
- จังหวัดปัตตานี (ทั้งจังหวัด)
- จังหวัดยะลา (ทั้งจังหวัด)
- จังหวัดนราธิวาส (ทั้งจังหวัด)
- จังหวัดสงขลา เฉพาะ 4 อำเภอ: จะนะ, เทพา, สะบ้าย้อย, นาทวี

> ทุก Project ต้องระบุพื้นที่ตามนี้เท่านั้น หากแหล่งข้อมูลใดนับสงขลาทั้งจังหวัด ต้องแยก/ประมาณการเฉพาะ 4 อำเภอ หรือระบุ caveat ให้ชัดเจนในรายงาน

---

## 3. ช่วงเวลาข้อมูล (Time Range)

**ปี 2021 - 2025** (5 ปีย้อนหลัง — ข้อมูลใหม่ที่สุด เหมาะกับผู้ประกอบการและนักลงทุน)

**กติกาเมื่อแหล่งไหนยังไม่มีปี 2025:**
- ใช้ปีล่าสุดที่มี (เช่น GPP อาจจบที่ 2024) และระบุใน source_log ว่าจบปีไหน
- เสริมด้วยข้อมูลที่ออกเร็ว (DBD, ศุลกากร, ท่องเที่ยว, BOI, Deep South Watch รายเดือน, รายงาน ธปท. รายไตรมาส) เพื่อให้เห็นภาพปี 2025
- ห้ามเอาตัวเลขประมาณการ/คาดการณ์มาปนกับตัวเลขจริง — ถ้าใช้ต้องติดป้าย "ประมาณการ"

**หมายเหตุ:** ปี 2021 ยังมีผลโควิด (ฐานต่ำ) — growth ปี 2022 อาจดูสูงเกินจริง ให้เทียบกับ CAGR ทั้งช่วงด้วย

---

## 4. แหล่งข้อมูลหลัก (Primary Data Sources)

| ด้าน | แหล่งข้อมูล |
|------|-------------|
| เศรษฐกิจ/GPP | สภาพัฒน์ (สศช.), ธนาคารแห่งประเทศไทย สำนักงานภาคใต้ |
| ธุรกิจ/การลงทุน | กรมพัฒนาธุรกิจการค้า (DBD), สำนักงานคณะกรรมการส่งเสริมการลงทุน (BOI) |
| ความมั่นคง/เหตุการณ์ | Deep South Watch, ศูนย์อำนวยการบริหารจังหวัดชายแดนภาคใต้ (ศอ.บต.) |
| การค้าชายแดน | กรมศุลกากร, กรมการค้าต่างประเทศ — ด่านในพื้นที่: สุไหงโก-ลก, ตากใบ, บูเก๊ะตา, เบตง, ประกอบ (สะเดา/ปาดังเบซาร์ ใช้เป็นตัวเทียบเท่านั้น) |
| ประชากร/แรงงาน | สำนักงานสถิติแห่งชาติ |

## 5. หน่วยวัดร่วม (Master Metrics)

ทุก Project ต้องใช้หน่วยวัดชุดนี้เป็นอย่างน้อย เพื่อให้ข้อมูลนำมาต่อกันได้ตอนรวม Dashboard:

- **GPP**: ล้านบาท + % การเติบโตเทียบปีก่อนหน้า (YoY)
- **ธุรกิจจดทะเบียนใหม่/เลิกกิจการ**: จำนวนราย/ปี แยกตามประเภทธุรกิจ
- **เหตุการณ์ความไม่สงบ**: จำนวนครั้ง/ปี + ความเสียหาย (ถ้ามีข้อมูล)
- **มูลค่าการค้าชายแดน**: ล้านบาท/ปี

## 6. Project Structure ใน Claude

แยกเป็น 4 Project อิสระ แนะนำตั้งชื่อให้สอดคล้องกัน เช่น:
1. `SBP Dashboard - Opportunity Mapping`
2. `SBP Dashboard - Development Priority`
3. `SBP Dashboard - Risk Factor Analysis`
4. `SBP Dashboard - Vulnerable Sectors`

> **สำคัญ:** ให้แปะเอกสารนี้ (Master Scope) ไว้เป็นข้อความแรกของทุก Project ใหม่ เพื่อกัน scope หลุด
